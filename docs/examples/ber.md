# BER Verification

End-to-end Bit Error Rate measurement of the full TX → channel → RX chain. The notebook produces:

1. **Point BER at nominal SNR** — single-run BER together with the receive-side SNR and Eb/N0
2. **BER vs Eb/N0 sweep** — full BER curve generated by sweeping the AWGN channel SNR, for direct comparison against the theoretical QAM-in-AWGN curve
3. **Sensitivity sweep — chip input plane** — sweeps TX input power downward and reports BER vs the power **at the LNA input** (the `AWGN` tap, just before the LNA), with the channel AWGN bypassed (`snr_db = 200`). The remaining noise sources are the LNA and RX-mixer NF only, so this measures true chip sensitivity rather than a system sensitivity that includes channel noise.
4. **Bench-test sensitivity — thermal noise only** — emulates a signal generator wired directly to the LNA via a coaxial cable: the TX chain (mixer, PA, path loss) is bypassed and the AWGN noise floor is held fixed at $kTB$ regardless of signal level. Because the noise power no longer scales with signal level, the AWGN SNR is recomputed at every sweep point.

**Key checks:**
- BER vs Eb/N0 follows the theoretical QAM-in-AWGN curve in the linear regime
- BER floors above a certain SNR when phase noise / nonlinearity dominate
- Sensitivity (minimum input power for a target BER) matches the analytical estimate from the link-budget notebook
